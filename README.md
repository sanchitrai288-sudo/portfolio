# Student Portfolio Website

A simple and elegant personal portfolio website built with HTML to showcase my background, skills, projects, and contact information in a clean and professional way.

## Features
- Home page with a welcoming introduction and overview of the website
- About Me section that shares personal details, interests, and achievements
- Projects & Skills section that highlights technical abilities and completed work
- Contact page with a simple contact form for visitors to reach out
- Easy navigation between all pages using a clear menu bar
- A visually appealing and beginner-friendly layout designed for presentation

## Technologies Used
- HTML5 for creating the structure of the website
- CSS3 for styling the layout, colors, spacing, and design elements
- GitHub Pages for hosting the project online

## Project Structure
- index.html - Main home page of the portfolio
- about.html - Contains information about the owner and personal background
- skills.html - Displays skills, projects, tools, and academic qualifications
- contact.html - Includes contact details and a form for communication

## About This Project
This portfolio website was created to present my academic background, technical skills, and projects in a professional and attractive format. The design is simple, user-friendly, and easy to understand, making it suitable for beginners and recruiters alike.

## How to View
You can open the HTML files directly in any browser to view the website locally. If you want to publish it online, you can host the project using GitHub Pages.
